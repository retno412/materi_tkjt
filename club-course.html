📊 Big-O Cheat Sheet Worst-case umum · n = ukuran input
O(1)Akses array per indeks, operasi hash map rata-rata
O(log n)Binary search, operasi balanced BST
O(n)Satu loop linear, pencarian tanpa urutan
O(n log n)Merge sort, heap sort, quick sort rata-rata
O(n²)Dua loop bersarang, bubble / insertion sort
O(2ⁿ)Brute force subset / backtracking tanpa pruning

Catatan akurasi: hash map rata-rata O(1) tetapi worst-case O(n); quick sort rata-rata O(n log n), worst-case O(n²). Selalu sebutkan kasus yang sedang diukur.

Level ini membuatmu mampu membangun produk utuh: dari antarmuka, data, autentikasi, sampai online di internet.
