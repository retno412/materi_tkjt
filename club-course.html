🗺️ Peta Perjalanan Belajar (Specialist Squad Roadmap)

Level 1: All Members

🌱 Foundation & Problem Solving

Wajib diikuti seluruh siswa baru untuk membangun logika berpikir komputasional dan pemahaman dasar koding.

  • Materi Utama: Computational Thinking, Algoritma Dasar, Git & GitHub Version Control, HTML5/CSS3 Fundamentals.
  • Target Platform Kredensial: TLX TOKI (Dasar), freeCodeCamp (Responsive Web), SoloLearn.
Level 2: Squad Specialist

🚀 Pemetaan Peminatan & Squad

Siswa memilih 1 spesialisasi sesuai bakat dan passion teknis setelah lulus tahap Foundation.

  • 🌐 Web Development Squad: JavaScript (ES6+), Node.js/Express, PHP Native/Laravel, REST API, Database (MySQL/PostgreSQL).
  • 📱 Mobile App Squad: Dart & Flutter Framework, State Management (Bloc/Provider), Local Storage, REST Integration.
  • 🎨 UI/UX & Digital Product Design: Figma, User Research, Wireframing, High-Fidelity Design, Design System, Usability Testing.
  • 🎮 Game Development Squad: Godot Engine / Unity 2D, C#, Sprite Animation, Game Physics, Game Logic & Level Design.
  • ☁️ Cloud, DevOps & Database Squad: Linux CLI, SQL Optimization, Docker Basics, Cloud Infrastructure (AWS/GCP Practitioner).
Level 3: Competitive Ready

🏆 Tim Lomba & Portofolio Industri

Siswa terpilih difokuskan untuk inkubasi kompetisi nasional dan pengerjaan proyek riil.

  • 🧠 Competitive Programming (CP) Squad: C++ STL, Analisis Kompleksitas Big-O, Structured Data (Vector/Map/Tree), Graph, Dynamic Programming.
  • 🎯 Target Kompetisi & Lomba: LKS SMK (Web Tech / Software Application), Olimpiade Informatika (NOI/KSN), Hackathon, Game Jam.
