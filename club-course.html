🗺️ Peta Perjalanan Belajar (Specialist Squad Roadmap)

Level 1: All Members

🌱 Foundation & Problem Solving

Membangun pola pikir komputasional mendasar untuk seluruh siswa sebelum masuk ke spesialisasi.

📘 Materi Utama (Portofolio Acuan):

  • Computational Thinking: Metode memecahkan masalah kompleks dengan cara memecahnya menjadi bagian-bagian kecil (dekomposisi, pengenalan pola, dan abstraksi).
  • Algoritma Dasar: Menyusun langkah-langkah sistematis dan logis untuk menyelesaikan instruksi program secara akurat.
  • Git & GitHub Version Control: Pengelolaan versi kode program serta kolaborasi pemuatan repositori proyek secara profesional.
  • HTML5 & CSS3 Fundamentals: Dasar pembentukan struktur halaman web interaktif dan penataan tata letak visual (responsive layout).

🎯 Target Platform Kredensial:

🔗 TLX TOKI (Dasar) 🔗 W3Schools 🔗 freeCodeCamp (Responsive Web) 🔗 SoloLearn
Level 2: Squad Specialist

🚀 Pemetaan Peminatan & Squad

Siswa memilih 1 spesialisasi sesuai minat dan bakat setelah menyelesaikan materi Foundation.

🌐 Web Development Squad:

  • JavaScript (ES6+), Node.js, Express.js, PHP Native/Laravel, REST API, & Database MySQL/PostgreSQL.

📱 Mobile App Squad:

  • Dart & Flutter Framework, State Management (Provider/Bloc), Local Storage, & REST API Integration.

🎨 UI/UX & Digital Product Design:

  • Figma Wireframing, User Research, High-Fidelity UI Design, Design System, & Usability Testing.

🎮 Game Development Squad:

  • Godot Engine / Unity 2D, C#, Sprite Animation, Game Physics, Game Logic, & Level Design.

☁️ Cloud, DevOps & Database Squad:

  • Linux CLI, SQL Query Optimization, Docker Fundamentals, & Cloud Infrastructure (AWS/GCP).
Level 3: Competitive Ready

🏆 Tim Lomba & Portofolio Industri

Inkubasi intensif untuk siswa terpilih guna mengikuti kompetisi nasional dan proyek tingkat lanjut.

🧠 Competitive Programming (CP) Squad:

  • C++ STL: Penggunaan Standard Template Library (Vector, Map, Set) untuk efisiensi koding.
  • Analisis Kompleksitas Big-O: Mengukur kecepatan eksekusi algoritma ($O(1)$, $O(n)$, $O(\log n)$).
  • Structured Data: Penerapan struktur data tingkat lanjut seperti Tree dan Graph.
  • Dynamic Programming: Teknik pemecahan masalah kompleks dengan menyimpan hasil perhitungan sebelumnya.

👥 Spesifikasi Tim Ideal Kompetisi Inovasi & Coding:

Dianalisis dari standar lomba nasional seperti JHIC 2.0 (Jagoan Hosting) & Hackathon, tim siap tanding dibentuk dari gabungan 3 peran utama (*The Triad*):

  • 👨‍💻 The Hacker (Lead Developer / Web Specialist): Menguasai logika koding, integrasi database, & hosting deployment (HTML/CSS/JS/PHP/Laravel atau Node.js).
  • 🎨 The Hipster (UI/UX Designer & Product Specialist): Menguasai Figma, wireframing, estetika antarmuka, serta penyusunan slide presentasi produk (*pitch deck*).
  • 💡 The Hustler / Pitcher (Business & Impact Lead): Memahami problem-solving, analisis dampak sosial/inovasi sekolah, serta kemampuan menyampaikan gagasan/pitching di hadapan juri.
  • 👨‍🏫 Mentor & Inovator (Guru / Staff IT): Membimbing kesesuaian solusi digital dengan kebutuhan nyata di sekolah dan mendampingi manajemen proyek tim.
